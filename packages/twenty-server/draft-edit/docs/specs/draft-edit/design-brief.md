# Design Brief — Twenty draft editing
Asset: crm:twenty-outreach · Project: twenty-outreach · Date: 2026-11-16 · Stage: Specced
## Positioning
Make editing feel like editing the selected draft with transparent failure states.
## References
Existing Twenty v2.58 draft controls and design system.
## Colour system
Reuse Twenty tokens.
## Typography
Reuse Twenty typography.
## Spacing, rhythm & layout
Reuse Twenty form layout.
## Functional acceptance (journeys)
J3 must navigate normally, edit, save, reopen, and display attachments and conflict errors.
## Component direction
Reuse existing editor and file controls where possible; no invented UI patterns.
## Anti-patterns for this project
Silent duplication, hidden attachment removal, implying a message was sent.
## Decisions
No new design language requested.
## Assumptions & open questions
- needs-confirmation — exact upstream editing surface must be inspected before UI work.
